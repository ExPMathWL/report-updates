How to use this page
Use the Report button on the student's details page in Radius to pull Assessment reports. For Numerical Fluency assessments, use the chart button. Click Preview to download the PDF.

Picking a mode up top changes what the rest of the page asks for:

  • Progress Update: for an existing family, built from their assessment PDFs.
  • Risk-Free Assessment: for a new lead's first assessment.

Quick rundown for Progress Update / RFA:

  • Step 1: drop in all of the student's PDFs at once, main assessment, Numerical Fluency (pull the chart, not the report), Computation, Extensions, whatever you've got, and hit Analyze all. Learning Plan Report PDFs get pulled out automatically to fill Step 4 below; they don't need separate handling.
  • Additional assessments (between Steps 1 and 2): anything that wasn't the main assessment lands here automatically, shown as a one-line summary once it's populated. Click Replace PDF on a card to swap its source, or + Add another assessment to attach one by hand.
  • Step 2: check the student's name, pronoun, and sender details, and fix anything that came in wrong.
  • Step 3: review the skill-by-skill breakdown and check the boxes for what's worth mentioning in the email.
  • Step 4: Learning Plan topics, auto-filled if a Learning Plan Report PDF was in the Step 1 batch, or type your own.
  • Step 5: generate the email, edit freely, then copy; bullets and formatting paste cleanly into Gmail.

Sibling mode (top of the page): run each sibling through their own tab, then generate one combined email covering all of them.

The East Vancouver / West Linn toggle up top drives center-specific wording and the signature block, so always double-check it matches before generating.

How to use Exit Summary mode

A different flow from Progress Update / RFA, since there's no PDF to parse: a multi-year exit narrative isn't in any single Radius export. Everything's entered by hand:

  • Fill in the student's info and, row by row, their milestone history (assessment name, start/end dates and scores). The tool chains these into a narrative, handles retakes automatically, and can build a simple score-over-time chart from the same data.
  • Write the personal note yourself; that part's deliberately not auto-generated.
  • Turn on Sibling mode at the top of this step for a combined family email, styled like the real MEV examples.
  • The cancellation / billing section is optional and shared across the whole email; anything left blank shows up as an obvious [FILL IN] placeholder rather than silently disappearing.

This mode is still being tested, so double-check the draft closely before sending.
