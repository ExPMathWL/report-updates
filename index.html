Upload Radius assessment-chart PDFs, review the results, and draft a parent email.

How to use this page
Use the Report button on the student's details page in Radius to pull assessment reports. Leave Expected Timeline unchecked, then click Preview to download the PDF. (Also double-check Results Display Format is set to Fraction, since that's what this tool reads.)

Quick rundown:

  • Upload all assessment reports.
  • Check the student details.
  • Review the analyzed scores and adjust as necessary.
  • Fill in the new learning plan topics by hand.
  • Generate the email.
