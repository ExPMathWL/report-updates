Progress Report Builder

Upload two Radius assessment-chart PDFs (or one comparison chart), review the results, and draft a parent update email.

How to use this page
Use the Report button on the student's details page in Radius to pull assessment reports. Leave Expected Timeline unchecked, then click Preview to download the PDF. (Also double-check Results Display Format is set to Fraction — that's what this tool reads.)

Quick rundown:

  • Upload all assessment reports.
  • Check the student details.
  • Review the analyzed scores and adjust as necessary.
  • Fill in the new learning plan topics by hand.
  • Generate the email.
1

Upload assessments

PDF exports from Radius

Upload one Comparison Chart (already has Pre/Post bars) in slot A, or two separate Assessment Charts — one in each slot. Slot order doesn't matter; the tool sorts by date automatically.

+

Additional assessments (optional)

Numerical Fluency, etc. — click to expand

For assessments outside the main skill chart — Numerical Fluency is the common one. Upload its PDF if it uses the same Radius report layout, or just fill in the summary by hand. These analyze on upload automatically, no separate button needed.

2

Student & assessment details

Edit anything that came in wrong

When checked, the results table below switches from "improved" to "showed mastery" (100% topics), and the email skips the score-comparison language since there's no previous score.

3

Review skill-by-skill results

Check the boxes you want to mention in the email

"Improved" is auto-checked where the score went up. "New at this level" is auto-checked for topics that only appear on the current assessment (grade-level-up case). Uncheck anything you don't want in the email, or edit any cell directly.

4

New learning plan topics

Pulled by hand from Radius / the Learning Plan report

One topic per line. These go in the "will be working on these topics" section of the email.
